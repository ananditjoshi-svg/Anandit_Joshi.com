# ananditjoshi.com

Personal website of Anandit Joshi — alternative investments technology
executive. Built as a Jekyll site, hosted on GitHub Pages at
https://ananditjoshi.com.

## Structure

- `index.html` — homepage
- `about/` — executive profile, focus areas, and career
- `ventures/` — ventures (coming soon)
- `_layouts/default.html` — shared header, menu, and footer (contact links live here)
- `assets/css/main.css` — all styling (colors and type are CSS variables at the top)
- `_config.yml` — site title and description
- `CNAME` — keeps the custom domain attached

## Editing

Edit any file directly on github.com (open the file → pencil icon → commit).
The site rebuilds automatically within a minute or two.
